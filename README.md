The original LINKON OT HTML is in `app/src/main/assets/index.html`.

## GitHub Actions

The workflow is `.github/workflows/build-apk.yml`.
It uses Gradle 8.9 directly, so **do not add a Gradle Wrapper step**.

Run it from GitHub: Actions -> Build LINKON OT APK -> Run workflow.
